# Epics

Orun-style work programs. Each epic is a folder carrying `epic.yaml` (the
declaration the platform reads: slug, key prefix, milestones with exit
criteria and task keys) beside its doc set. The pull request that adds the
folder is the adoption; the merge creates the epic in the workspace.

| Epic | Cluster | Status | What it is |
|------|---------|--------|------------|
| [`on-demand-isr/`](./on-demand-isr/) | **OI** | In progress (OI1: the site on Workers) | Vercel's On-Demand ISR template on Cloudflare Workers — a repository's GitHub issues as pages cached in R2, regenerated by a GitHub App's signed webhook through the Durable Object tag cache — and an Orun baseline that instantiates it in one landing, live before an App is connected (OI2) |

As-built ≠ intent: what shipped lives in each epic's `IMPLEMENTATION-STATUS.md`.
